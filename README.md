# 經濟棋局 · 併購派對

3D 骰子派對棋盤遊戲。2–8 位玩家可在同一台電腦輪流遊玩，也可用 6 碼房間代碼跨頁籤／跨裝置連線。擲骰、踩格、抽道具、放技能、買星、併購，最後把整座棋盤收進口袋。

直接開啟 [index.html](./index.html) 即可單機遊玩；多人與遠端連線請用 `node serve.mjs` 啟動本機伺服器。

## 遊戲模式

| 模式 | 勝利條件 | 特色 |
| --- | --- | --- |
| 🌟 企業之星 | 先拿 3 顆星；或季末星數最高 | 經過或停留在出發格都能買星，星價 500 起，全場每賣 1 顆 +500，可付「星價 + 300」強買對手的星 |
| 💰 首富競爭 | 總資產率先達到 8,000 | 季數過半通膨 ×2，倒數兩季 ×4，資產與踩格收益同步放大 |
| 💀 邪惡企業 | 成為唯一倖存者；季末比較生還季數 | 每 5 季毀滅日雷射收保護費（初始 1,000，每次收取後漲價，由首富開始），付不出來化為藍色罷工幽靈 |
| 🎲 隨機模式 | 依抽到的模式 | 開局從企業之星、首富競爭、邪惡企業隨機抽一種，並套用固定預設數值 |

三種模式的季數、勝利星數、總資產目標、保護費間隔與初始保護費，都在「開啟測試（單機沙盒）」旁依模式顯示並鎖定；隨機模式全部鎖定，固定為企業之星 10 季／3 星、首富競爭 24 季／8,000、邪惡企業 20 季／首期保護費 1,000。

企業之星與首富競爭若第一名平手，會進入驟死賽：憤怒幽靈移動 ×1.5、扣款 ×2。

## 玩法

1. 選擇 2–8 位玩家與企業角色，再依模式設定季數上限與勝利條件。每位玩家初始總資產 1,200、技能能量 1 點。
2. 每回合開始自動抽 1 個道具（普通與神話共用 3 格）；滿了必須先丟棄才能取得新道具。擲骰前可自由使用道具或發動企業技能；技能每次消耗 1 點能量。
3. 擲出單顆六面骰（1–6），棋子逐格前進。經過或停留在起點領 200 總資產；企業之星模式還會彈出買星視窗。
4. 骰子停下、棋子完全靜止後才會結算格子效果、觸發互動視窗或幽靈事件。
5. 格子效果：
   - **藍色發財格**：獲得 300 總資產。
   - **紅色蕭條格**：扣除 150 營運費。
   - **黃色技能格**：補充 1 點技能能量（上限 9）。
   - **綠色事件格**：立刻抽一張即時事件。
   - **罷工幽靈**：只有「踩在幽靈格」才觸發，扣 1,000 總資產並隨機沒收 1 個道具。幽靈格是灰色斜線格，滑鼠移上去可看效果；幽靈每次結束回合隨機移動 1–3 格。
6. 停在普通格後抽一張「二選一」快速決策，共有六種情境，選項會即時生效。
7. 停在出發格或經過出發格時，企業之星可購買星星；先拿到目標星數的人立刻獲勝。
8. 總資產達 2,000 可併購一位對手，讓對方成為子公司；子公司每回合上繳 40% 收益，存到 1,000 可花 1,000 獨立反撲。
9. 所有玩家完成行動後結算一季；到達季數上限時依模式比較排名。

## 動態地圖與特殊格

每局隨機生成 24 格，並保證特殊格互不相鄰：

- **🛒 黑市 ×3**：神話道具拍賣，起標 1,000，每次抬價 250。
- **📈 投資 ×2**：投入 50% 總資產換股票憑證；季末大牛市 ×3（10%）、平穩 ×1.5（40%）、龐氏騙局歸零（50%）。
- **🏛️ 查稅局 ×1**：繳 50% 總資產，或接受 2 回合羈押。
- **🌈 內線交易 ×1**：花 100 轉命運輪盤，用完變回普通格並在別處重生。

## 道具與企業技能

五種普通道具各有 20% 抽取機率：🛡️ 買保險、🎲 123 骰子、🎲 456 骰子、🔄 移形換位、📈 開槓桿。道具欄旁有 🗑️ 可直接丟棄。

黑市限定 8 款神話道具，與普通道具共用 3 格欄位：🗿 不死圖騰、🎫 贖罪券 ×5、⬆️ 矢量操作、🚪 真理之門（3 充能）、🗡️ 斬魄刀、❄️ 寒冰蘑菇、🦠 魔女因子、🌐 弱者的領域。

黑市得標時若背包已滿（3/3），必須選擇替換一個現有道具，或丟棄剛得標的新道具（丟棄需二次確認，且不退還拍賣金額）。

真理之門金錢轉道具只能煉成普通道具；總資產不足 1,000、背包已滿或處於卍解時按鈕會變暗不可點。背包沒有道具時也無法把道具煉成金錢。

🗡️ 斬魄刀取得時是無特殊效果的基礎型態；持有者成功買到星星時，會就地進化為 🌀 卍解，獲得收益 +100、負面免疫與禁止取得新道具。若星星被偷走，卍解會退化回斬魄刀。

🦠 魔女因子在踩中幽靈後觸發「死亡回歸」，全場狀態回溯至本回合初，並播放負片濾鏡與專案內建 `witch_factor.mp3`。

🌐 弱者的領域以藍色框線標示在棋盤上；對手進入時會出現明顯的扣款標籤、震動特效與專屬音效。

十種企業各有專屬技能：炎上商法、計畫性報廢、購物節狂歡、惡意做空、垃圾食物成癮、幽靈派單、凍結帳戶、強制徵收、碳稅制裁、零日漏洞。大廳另可選「未定新創集團 🎲」，開局隨機分配企業。完整數值與說明請看遊戲內「規則說明」。

## 多人連線

1. 執行 `node serve.mjs`，開啟 <http://127.0.0.1:4173/>；此伺服器只提供靜態檔案。
2. 房主建立房間取得 PeerJS ID；其他玩家輸入完整 ID 加入，選擇企業後由房主開始。
3. 遊戲資料透過 PeerJS WebRTC DataConnection 在玩家瀏覽器間傳送；PeerJS 訊號服務只負責協助建立連線。
4. 對局狀態由房主統一轉發；互動視窗只會在目前決策者的本機端出現。其他玩家維持純觀戰視角，只看到「等待（玩家名稱）決定中...」，不會顯示對手道具格或可操作面板。拍賣期間僅目前出價者可操作。
5. 結束後開啟結算頁（總資產圖表、生還季數與道具明細表格）。星數排行僅企業之星模式顯示；邪惡企業全員淘汰時副標題為「無人生還」。每位玩家按「確認結果」，全員確認後一起回到同一個等待大廳。
6. 企業之星與首富競爭結束時有專屬結局過場動畫；邪惡企業毀滅日雷射會精準命中被淘汰玩家的棋子，至少播放 0.5 秒後才可開啟結算。

PeerJS 透過 HTML 載入 unpkg CDN；建立連線需要網路存取 PeerJS 訊號服務。靜態頁面可部署至任意 HTTP(S) 主機。

## 存檔

遊戲自動儲存在瀏覽器 `localStorage`。可從頂端匯出 JSON 或匯入舊存檔；存檔保留種子、回合、總資產、星數、能量、道具、神話道具、護盾、子公司、憑證與所有暫時狀態。第 1 版財務模擬存檔可直接匯入並自動遷移。

## 音效

內建程序化 WebAudio 音效，右上角可調整音量或靜音；設定會保存在瀏覽器。賺錢、扣錢、使用技能、弱者領域扣款與魔女因子都有專屬音效；魔女因子另會播放專案內的 `witch_factor.mp3`。

## 開發

- `data.js`：原始企業、道具、棋盤、事件與常數。
- `party_data.js`：新模式、翻新技能、神話道具、特殊格、輪盤與快速決策。
- `engine.js`：原始引擎與擴充掛鉤（8 人、幽靈落地、決策、回合／結算）。
- `party_engine.js`：動態棋盤、通膨、拍賣、投資、查稅、內線、技能、神話道具、毀滅日、驟死賽、結算資料與除錯工具。
- `app.js`、`ui_party.js`、`styles.css`、`party-ext.css`、`index.html`：介面、大廳、動畫、結算與匯出匯入。
- `net.js`：房間、WebRTC、BroadcastChannel 與 HTTP 訊號備援。
- `audio_system.js`：WebAudio 音效管理。
- `serve.mjs`：靜態檔案＋多人訊號伺服器（`PORT`、`HOST` 可覆寫）。
- `game.js`：供直接開啟 HTML 的合併腳本。

修改來源後執行 `node build.mjs`；沒有 Node.js 時可執行 `powershell -ExecutionPolicy Bypass -File .\build.ps1` 更新 `game.js`。規則、派對擴充與同步測試以 `node --test` 執行（`engine.test.js`、`party_engine.test.js`、`sync.test.js`）。

本遊戲的數字與事件僅供娛樂使用，不構成任何投資建議。
